# Abbey Street Barbers — Demo Website

A responsive, single-page barber shop website concept designed to help present and sell a professional online presence to local barbers.

## Preview

Open `index.html` in a browser, or enable GitHub Pages for this repository to share a live demo link.

## What's included

- Mobile-friendly layout and navigation
- Services and example pricing
- Shop story, customer testimonial, opening hours, address and click-to-call link
- Interactive appointment request form demo
- No build tools or dependencies required

## Before using this for a real shop

This is a fictional sales demo. Update the shop name, address, phone, prices, hours, and customer quote with approved details. The booking form currently shows a demo confirmation only; connect it to the shop's booking provider or a secure backend before accepting real appointments. The current text and prices are sample content, not verified business information.

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will provide a public preview URL after deployment.
